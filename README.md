# Coffee Shop Order Management System - CS151 Fall 2025

## Overview
A Java-based system simulating coffee shop operations including order management, customer tracking, and barista workflows.

## Design
- **Classes**: Person, Customer, Barista, MenuItem, Order, CoffeeShop
- **Interface**: Billable
- **Abstract Class**: Person

## Installation Instructions
1. Clone this repository
2. Navigate to the project directory
3. Compile: `javac src/*.java`
4. Run: `java src/CoffeeShop`

## Usage
Run the program and follow the text-based menu to manage coffee shop orders.
